# Architecture Decision Records

В данном каталоге хранятся все архитектурные решения проекта.

Каждый ADR является неизменяемым документом после принятия.

Рекомендуемая схема именования:

```
ADR-0001-<name>.md
ADR-0002-<name>.md
...
```

Статусы:

- Proposed
- Accepted
- Superseded
- Rejected

Изменение принятого решения оформляется новым ADR.
