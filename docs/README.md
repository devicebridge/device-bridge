# Документация Device Bridge

Документация проекта разделена на несколько независимых разделов.

| Каталог | Назначение |
|----------|------------|
| `adr/` | Архитектурные решения (Architecture Decision Records) |
| `pr/` | Описание завершённых Pull Request |
| `architecture/` | Архитектурные схемы, диаграммы и обзор компонентов |

Документация ведётся на русском языке.

Любое изменение архитектуры сначала оформляется новым ADR, после чего реализуется в коде.
