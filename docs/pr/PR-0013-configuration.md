# PR-0013 Configuration

## Статус

Merged

---

## Цель

Вынести настройки runtime из `cmd/device-bridge/main.go` во внешнюю конфигурацию.

После завершения PR адрес и порт HTTP-сервера не должны быть жёстко зашиты в коде. Конфигурация загружается из переменных окружения и передаётся в runtime.

---

## Выполненные изменения

Создан пакет:

```
internal/config
```

Добавлен тип:

```go
type Config struct {
    HTTPHost string
    HTTPPort int
}
```

Добавлены методы:

- `Load() (*Config, error)`
- `Config.ListenAddr() string`

Изменён:

- `cmd/device-bridge/main.go` — конфигурация загружается из переменных окружения.

---

## Конфигурация

| Переменная                | Назначение       | Default   |
| ------------------------- | ---------------- | --------- |
| `DEVICE_BRIDGE_HTTP_HOST` | HTTP listen host | `0.0.0.0` |
| `DEVICE_BRIDGE_HTTP_PORT` | HTTP listen port | `8080`    |

---

## Принятые решения

- Конфигурация загружается из переменных окружения.
- Значения по умолчанию (`0.0.0.0`, `8080`) находятся в пакете `config`.
- Некорректное значение порта (нечисловое или вне диапазона 1–65535) приводит к ошибке при загрузке.
- `main.go` получает конфигурацию и собирает runtime.
- Файлы конфигурации (YAML/TOML/JSON) не используются.
- Внешние библиотеки для конфигурации не добавляются — используется только стандартная библиотека Go.

---

## Архитектурные решения

- Конфигурация находится вне компонентов — принцип «Конфигурация является внешней» соблюдён.
- Environment variables читаются только конфигурационным слоем (`internal/config`).
- `main` получает конфигурацию и собирает runtime.
- HTTP Server не знает об environment.
- Bridge не знает об environment.
- WebSocket Handler не знает об environment.

---

## Тестирование

Добавлены unit-тесты:

- значения по умолчанию при отсутствии переменных окружения;
- переопределение через `DEVICE_BRIDGE_HTTP_HOST` и `DEVICE_BRIDGE_HTTP_PORT`;
- некорректный порт: нечисловое значение, `0`, `65536`, `-1`, `99999`;
- формирование listen address (`0.0.0.0:8080`, `127.0.0.1:9090`).

---

## Совместимость

Обратная совместимость сохранена. Запуск без переменных окружения эквивалентен предыдущему поведению: HTTP-сервер слушает `0.0.0.0:8080`, WebSocket endpoint `/ws`.

Дополнительные внешние зависимости не добавлены.

---

## Что намеренно НЕ входит

В данный PR не входят:

- YAML/TOML/JSON конфигурационные файлы;
- CLI flags;
- внешние библиотеки конфигурации (Viper, Cobra и т.д.);
- конфигурация Sources;
- конфигурация Scanner;
- конфигурация WebSocket endpoint;
- конфигурация Bus buffer;
- конфигурация Hub;
- configuration reload / hot reload;
- динамическое изменение конфигурации.

---

## Результат

HTTP host и port больше не захардкожены в `main.go`. Конфигурация загружается из переменных окружения и передаётся в runtime. Поведение по умолчанию сохранено.
