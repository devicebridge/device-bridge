# PR-0010b Thread-safe Hub

## Статус

Merged

---

## Цель

Сделать компонент Hub потокобезопасным перед добавлением первого сетевого транспортного адаптера.

---

## Выполненные изменения

- Добавлен `sync.RWMutex`.
- Защищены методы `Register()`.
- Защищены методы `Unregister()`.
- Защищён метод `Broadcast()`.
- Добавлен тест конкурентного доступа.

---

## Причина

После появления WebSocket методы Hub будут вызываться из нескольких goroutine.

Использование `sync.RWMutex` обеспечивает корректную работу при одновременной регистрации клиентов, их удалении и рассылке сообщений.

---

## Архитектурные решения

Архитектура проекта не изменялась.

Изменение носит исключительно технический характер и обеспечивает потокобезопасность существующего API.

---

## Совместимость

Публичный API Hub не изменился.

Все существующие тесты продолжают успешно выполняться.

---

## Особенности реализации

Используется `sync.RWMutex`.

Для рассылки сообщений применяется `RLock()`, что позволяет выполнять несколько операций чтения одновременно при отсутствии модификации списка клиентов.
