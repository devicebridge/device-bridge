# PR-0011 WebSocket Adapter

## Статус

Merged

---

## Цель

Добавить первый транспортный адаптер — WebSocket.

После завершения PR браузер должен иметь возможность подключиться по WebSocket и получать все сообщения, публикуемые Hub.

Никакой бизнес-логики не добавляется. WebSocket является исключительно транспортом.

---

## Выполненные изменения

Создан пакет:

```
internal/websocket
```

Добавлены типы:

```go
type Client struct
type Handler struct
```

Добавлены методы:

- `NewClient()`
- `Client.Send()`
- `NewHandler()`
- `Handler.ServeHTTP()`

---

## Принятые решения

- Используется библиотека `github.com/gorilla/websocket`.
- Используется `websocket.Upgrader` (не устаревший `Upgrade()`).
- `CheckOrigin` не переопределён — используется безопасное поведение библиотеки по умолчанию.
- `Client` реализует интерфейс `hub.Client`.
- Сериализация `Message` в JSON происходит только внутри `Client.Send()`.
- `Handler` не знает ничего о формате `Message`.
- `Handler` только принимает HTTP-запрос, выполняет upgrade, создаёт `Client`, регистрирует его в `Hub`, ожидает закрытия соединения, удаляет `Client` из `Hub`.

---

## Особенности реализации

- Используется `gorilla/websocket`.
- Один конкурентный writer защищён `sync.Mutex`.
- Соединение постоянно читается для корректной обработки закрытия.
- Используется стандартная безопасная политика `CheckOrigin`.

---

## Тестирование

Добавлены тесты:

- создание `Client`;
- создание `Handler`;
- отправка сообщения через `Client.Send()` и проверка сериализации;
- интеграционный тест полного цикла:
  - `Hub` → `Broadcast()` → `Client.Send()` → WebSocket → `ReadMessage()` → `json.Unmarshal()` → сравнение всех полей `Message`;
- интеграционный тест с несколькими последовательными сообщениями.

Тесты используют `httptest.Server` и `websocket.DefaultDialer`. Mock-объекты WebSocket не используются.

---

## Архитектурные решения

Новые архитектурные решения не принимались.

WebSocket-адаптер является первым транспортным адаптером проекта. Он следует принятому принципу: транспорт не содержит бизнес-логики.

---

## Совместимость

Изменений, нарушающих обратную совместимость, нет.

Добавлена внешняя зависимость `github.com/gorilla/websocket`.

---

## Что намеренно НЕ входит

В данный PR не входят:

- подключение WebSocket к Bridge runtime;
- аутентификация;
- конфигурация WebSocket;
- другие транспортные адаптеры.

---

## Результат

Проект получил первый транспортный адаптер WebSocket. Браузер может подключиться по WebSocket и получать все сообщения, публикуемые Hub.
