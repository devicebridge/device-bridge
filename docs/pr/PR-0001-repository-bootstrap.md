# PR-0001 Repository Bootstrap

## Статус

Merged

---

## Цель

Создать минимальный каркас репозитория, достаточный для начала разработки проекта Device Bridge.

После завершения данного PR репозиторий должен:

- успешно собираться;
- проходить базовые проверки CI;
- содержать необходимую документацию;
- служить основой для последующих небольших Pull Request.

---

## Выполненные изменения

### Репозиторий

Добавлены:

- `go.mod`
- `.gitignore`
- `LICENSE`
- `README.md`
- `Makefile`

---

### Точка входа

Создана минимальная точка входа приложения:

```
cmd/device-bridge/main.go
```

Приложение успешно компилируется и запускается.

---

### CI

Добавлен GitHub Actions workflow.

Проверяются:

- форматирование (`go fmt`)
- статический анализ (`go vet`)
- тесты (`go test`)
- сборка (`go build`)

---

### Документация

Создан раздел `docs`.

Добавлены подразделы:

- `docs/adr`
- `docs/pr`
- `docs/architecture`

Подготовлены README-файлы для каждого раздела.

---

## Архитектурные решения

В рамках данного PR архитектурные решения **не принимались**.

Все ранее согласованные архитектурные решения считаются внешними по отношению к данному PR.

---

## Что намеренно НЕ входит

В данный PR сознательно не включены:

- конфигурация;
- очередь сообщений;
- WebSocket;
- Source API;
- логирование;
- внутренние пакеты;
- плагины;
- Docker;
- релизная автоматизация.

Это позволяет сохранить PR минимальным и полностью работоспособным.

---

## Проверка

Выполняются без ошибок:

```bash
go build ./...
```

```bash
go test ./...
```

```bash
make build
```

---

## Результат

Репозиторий готов к дальнейшей разработке.

Следующий PR может начинать реализацию первой функциональности без необходимости изменения инфраструктуры проекта.

## Совместимость

Сборка выполняется без CGO для обеспечения максимальной переносимости бинарного файла между Linux-дистрибутивами.

Проект не использует системные динамические библиотеки на данном этапе.

Изменений, нарушающих обратную совместимость, нет.
