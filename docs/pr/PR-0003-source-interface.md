# PR-0003 Source Interface

## Статус

Merged

---

## Цель

Добавить контракт для источников данных.

Source является компонентом, который получает данные из внешнего мира и публикует транспортные сообщения.

---

## Выполненные изменения

Создан пакет:

```
internal/source
```

Определён интерфейс:

```go
type Source interface {
	Run(chan<- message.Message) error
}
```

Интерфейс не зависит от конкретных транспортов, оборудования и реализации Bridge.

---

## Тестирование

Добавлен compile-time тест, подтверждающий корректность реализации интерфейса.

---

## Архитектурные решения

Новые архитектурные решения не принимались.

Интерфейс соответствует ранее утверждённой архитектуре.

---

## Совместимость

Изменений, нарушающих обратную совместимость, нет.

---

## Что намеренно НЕ входит

В данный PR не входят:

- реализация источников;
- фабрика Source;
- регистрация Source;
- очередь сообщений;
- WebSocket;
- конфигурация.

---

## Результат

Проект получил первый контракт для реализации источников данных.
