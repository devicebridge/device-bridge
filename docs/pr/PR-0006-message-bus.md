# PR-0006 Message Bus

## Статус

Merged

---

## Цель

Добавить компонент передачи транспортных сообщений между источниками данных и последующими обработчиками.

Bus является простым транспортным уровнем и не содержит бизнес-логики.

---

## Выполненные изменения

Создан пакет:

```
internal/bus
```

Добавлен тип:

```go
type Bus struct
```

Добавлены методы:

- `New(size int)`
- `Publish(message.Message)`
- `Subscribe()`

---

## Принятые решения

- Bus использует встроенный канал Go.
- Bus имеет одного подписчика.
- Bus не реализует механизм Pub/Sub.
- Рассылка нескольким WebSocket-клиентам является ответственностью WebSocket Hub.
- Bus не управляет собственным жизненным циклом.

---

## Тестирование

Добавлены unit-тесты:

- создание Bus;
- публикация и получение сообщения;
- работа буферизированного канала;
- сохранение порядка сообщений.

---

## Архитектурные решения

Новые архитектурные решения не принимались.

Использование встроенного канала Go соответствует архитектуре проекта и принципу минимальной сложности.

---

## Совместимость

Изменений, нарушающих обратную совместимость, нет.

---

## Что намеренно НЕ входит

В данный PR не входят:

- WebSocket Hub;
- управление жизненным циклом;
- закрытие Bus;
- маршрутизация сообщений;
- несколько подписчиков.

---

## Результат

Проект получил первый рабочий транспортный компонент для передачи сообщений между внутренними подсистемами.
