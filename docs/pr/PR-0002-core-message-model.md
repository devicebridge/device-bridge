# PR-0002 Core Message Model

## Статус

Merged

---

## Цель

Добавить базовую модель транспортного сообщения версии 1.0.

Сообщение является единым контрактом обмена данными между всеми компонентами Device Bridge.

---

## Выполненные изменения

Создан пакет:

```
internal/message
```

Добавлен тип:

```go
type Message struct {
    Source    string
    Timestamp int64
    Payload   string
}
```

Для всех полей определены JSON-теги, соответствующие спецификации протокола версии 1.0.

---

## Тестирование

Добавлены unit-тесты:

- сериализация в JSON;
- десериализация из JSON.

Проверено соответствие утверждённому формату сообщения.

---

## Архитектурные решения

Новые архитектурные решения не принимались.

Реализована модель, ранее утверждённая в архитектуре проекта.

---

## Совместимость

Изменений, нарушающих обратную совместимость, нет.

---

## Что намеренно НЕ входит

В данный PR не входят:

- очередь сообщений;
- WebSocket;
- обработчики;
- Source API;
- конфигурация;
- логирование.

---

## Результат

Проект получил первый стабильный транспортный контракт, который будет использоваться всеми последующими компонентами.
