# PR-0005 Bridge

## Статус

Merged

---

## Цель

Добавить центральный компонент приложения.

Bridge является владельцем основных компонентов системы и отвечает за их создание, связывание и дальнейшее управление жизненным циклом.

---

## Выполненные изменения

Создан пакет:

```
internal/bridge
```

Добавлен тип:

```go
type Bridge struct
```

Добавлен конструктор:

```go
func New() *Bridge
```

При создании Bridge автоматически создаётся собственный экземпляр Registry.

---

## Принятые решения

- Bridge является владельцем Registry.
- Bridge отвечает за композицию компонентов приложения.
- Bridge не содержит бизнес-логики.
- Bridge не взаимодействует напрямую с оборудованием.
- Bridge пока не управляет жизненным циклом приложения.

---

## Тестирование

Добавлен unit-тест конструктора Bridge.

Проверяется:

- успешное создание Bridge;
- создание внутреннего Registry.

---

## Архитектурные решения

Новые архитектурные решения не принимались.

Реализована ранее утверждённая архитектура проекта.

---

## Совместимость

Изменений, нарушающих обратную совместимость, нет.

---

## Что намеренно НЕ входит

В данный PR не входят:

- запуск приложения;
- Message Bus;
- WebSocket Hub;
- конфигурация;
- регистрация Source;
- управление жизненным циклом.

---

## Результат

Проект получил центральный компонент, который станет точкой композиции всех последующих подсистем.
