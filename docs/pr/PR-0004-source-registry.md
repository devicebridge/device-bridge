# PR-0004 Source Registry

## Статус

Merged

---

## Цель

Добавить реестр источников данных.

Registry отвечает за регистрацию фабрик и создание экземпляров Source по имени.

---

## Выполненные изменения

Создан компонент:

```
internal/source/registry.go
```

Добавлены:

- тип `Factory`;
- тип `Registry`;
- регистрация фабрик;
- создание Source по имени;
- проверки ошибок регистрации и создания.

---

## Принятые решения

- Registry не является глобальным объектом.
- Регистрация выполняется явно.
- Factory не принимает параметры.
- Factory не возвращает ошибку.
- Registry не использует синхронизацию.

---

## Тестирование

Добавлены unit-тесты:

- создание Registry;
- успешная регистрация;
- повторная регистрация;
- создание зарегистрированного Source;
- попытка создания неизвестного Source.

---

## Архитектурные решения

Новые архитектурные решения не принимались.

Registry реализует ранее согласованную архитектуру проекта.

---

## Совместимость

Изменений, нарушающих обратную совместимость, нет.

---

## Что намеренно НЕ входит

В данный PR не входят:

- реализации Source;
- конфигурация;
- очередь сообщений;
- WebSocket;
- жизненный цикл приложения.

---

## Результат

Проект получил механизм регистрации и создания источников данных, который станет основой для подключения конкретных реализаций в последующих PR.
