# PR-0010 HTTP Server

## Статус

Merged

---

## Цель

Добавить HTTP-сервер как отдельный инфраструктурный компонент проекта.

Сервер предоставляет маршрутизацию HTTP-запросов и не зависит от WebSocket или внутренних компонентов транспортного слоя.

---

## Выполненные изменения

Создан пакет:

```
internal/server
```

Добавлен тип:

```go
type Server struct
```

Добавлены методы:

- `New()`
- `Handle()`
- `Handler()`

---

## Принятые решения

- Используется стандартная библиотека `net/http`.
- Основа маршрутизации — `http.ServeMux`.
- Сервер предоставляет только `http.Handler`.
- Запуск HTTP-сервера выполняется внешним кодом.
- WebSocket не входит в данный PR.

---

## Тестирование

Добавлены unit-тесты:

- создание сервера;
- регистрация маршрута;
- обработка HTTP-запроса;
- возврат `404 Not Found` для неизвестного маршрута.

---

## Архитектурные решения

Новые архитектурные решения не принимались.

HTTP-сервер является независимым инфраструктурным компонентом и не зависит от остальных подсистем проекта.

---

## Совместимость

Изменений, нарушающих обратную совместимость, нет.

---

## Что намеренно НЕ входит

В данный PR не входят:

- запуск HTTP-сервера;
- WebSocket;
- HTTP API;
- обработчики проекта;
- конфигурация.

---

## Результат

Проект получил независимый HTTP-компонент, который станет основой для подключения WebSocket и других HTTP-маршрутов.
