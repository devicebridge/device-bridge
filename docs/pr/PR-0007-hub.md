# PR-0007 Hub

## Статус

Merged

---

## Цель

Добавить компонент Hub, отвечающий за рассылку транспортных сообщений зарегистрированным клиентам.

Hub является внутренним компонентом системы и не зависит от конкретных транспортных протоколов.

---

## Выполненные изменения

Создан пакет:

```
internal/hub
```

Добавлены:

- интерфейс `Client`;
- тип `Hub`;
- регистрация клиентов;
- удаление клиентов;
- рассылка сообщений.

---

## Принятые решения

- Hub работает с абстрактным интерфейсом `Client`.
- Hub не зависит от HTTP.
- Hub не зависит от WebSocket.
- Hub является пассивным компонентом.
- Hub не читает сообщения самостоятельно.
- Вызов `Broadcast()` выполняется внешним компонентом.

---

## Тестирование

Добавлены unit-тесты:

- создание Hub;
- регистрация клиента;
- удаление клиента;
- рассылка одному клиенту;
- рассылка нескольким клиентам;
- обработка ошибки клиента.

---

## Архитектурные решения

Новые архитектурные решения не принимались.

Hub реализует ранее согласованную архитектуру проекта и отделяет внутреннюю логику рассылки сообщений от конкретных транспортных технологий.

---

## Совместимость

Изменений, нарушающих обратную совместимость, нет.

---

## Что намеренно НЕ входит

В данный PR не входят:

- HTTP-сервер;
- WebSocket Upgrade;
- реализация WebSocket-клиента;
- чтение из Message Bus;
- управление жизненным циклом.

---

## Результат

Проект получил независимый компонент рассылки сообщений, который может использоваться с любым транспортом, реализующим интерфейс `Client`.
