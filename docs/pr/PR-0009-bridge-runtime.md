# PR-0009 Bridge Runtime

## Статус

Merged

---

## Цель

Добавить Runtime, связывающий внутренние компоненты приложения.

Runtime получает сообщения из Message Bus и передаёт их в Hub.

---

## Выполненные изменения

Добавлен метод:

```go
func (b *Bridge) Run()
```

Bridge Runtime:

- читает сообщения из Bus;
- вызывает Hub.Broadcast() для каждого сообщения.

---

## Принятые решения

- Runtime является связующим компонентом между Bus и Hub.
- Runtime не изменяет сообщения.
- Runtime не содержит бизнес-логики.
- Runtime выполняется синхронно.
- Запуск Runtime осуществляется вызывающей стороной.

---

## Тестирование

Добавлен интеграционный тест.

Проверяется полный внутренний маршрут сообщения:

```
Bus
 ↓
Runtime
 ↓
Hub
 ↓
Client
```

---

## Архитектурные решения

Новые архитектурные решения не принимались.

Runtime реализует ранее утверждённую архитектуру проекта и отвечает исключительно за связывание компонентов.

---

## Совместимость

Изменений, нарушающих обратную совместимость, нет.

---

## Что намеренно НЕ входит

В данный PR не входят:

- context.Context;
- остановка Runtime;
- логирование;
- HTTP;
- WebSocket;
- конфигурация.

---

## Результат

Проект получил первый работающий внутренний конвейер передачи сообщений между компонентами.

Текущая реализация Run() является бесконечным циклом. Управление жизненным циклом и корректная остановка Runtime будут добавлены отдельным PR.
