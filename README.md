# Device Bridge

Device Bridge — легковесный транспортный слой между локальными источниками данных и web-приложениями.

## Цели проекта

- единый транспорт между устройствами и web-клиентами;
- отсутствие бизнес-логики внутри Bridge;
- минимальные зависимости;
- один исполняемый файл;
- простая интеграция с различными источниками данных.

## Принципы

- Bridge не знает протоколов оборудования.
- Источники (Sources) самостоятельно получают данные.
- Все сообщения публикуются в общую очередь.
- WebSocket рассылает сообщения всем подключенным клиентам.

## Формат сообщения

```json
{
  "source": "scanner-main",
  "timestamp": 1785472345123,
  "payload": "..."
}
```

Поле `meta` зарезервировано для будущих версий протокола и в версии 1.0 отсутствует.

## Статус

Проект находится в активной разработке.
